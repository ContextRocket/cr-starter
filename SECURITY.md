# Security Policy

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Report security issues privately via
[GitHub Security Advisories](https://github.com/your-org/cr-starter/security/advisories/new).

Include:

- A clear description of the vulnerability.
- Steps to reproduce or a proof-of-concept if possible.
- The potential impact (data exposure, auth bypass, etc.).
- Your recommended fix if you have one.

We will acknowledge your report within 48 hours and aim to resolve confirmed
vulnerabilities within 14 days. We will credit you in the changelog unless you
prefer to remain anonymous.

## Scope

This policy covers the cr-starter template itself. Vulnerabilities in your
fork, your ContextRocket org configuration, or third-party dependencies should
be reported to the appropriate upstream maintainer.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| latest  | Yes       |

Only the latest commit on `main` is supported. Pin to a specific commit if you
need a reproducible deployment.
