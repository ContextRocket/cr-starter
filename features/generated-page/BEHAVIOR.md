# Supplied generated page build

- **GENERATED-001:** Accept the pinned product `LandingPageManifest` JSON Schema,
  English locale and `/p/{page_slug}/` route. Refuse unsupported visible sections,
  unsafe links, changed pins and missing or foreign capability bindings.
- **GENERATED-002:** Execute Astro from isolated source, reuse shared layout and
  browser components, and package its static output with the SDK. Equal inputs
  produce equal archives. Facts remain links to a separate managed bundle.
- **GENERATED-003:** Send lead forms through the SDK Contacts transport with the
  exact supplied App UUID and attribution. Show success only after a valid
  capture receipt. Failed or malformed responses keep the form available.

Never: publish during a build, fabricate capture success, emit Facts files, load
provider credentials, or change the selected route namespace.
