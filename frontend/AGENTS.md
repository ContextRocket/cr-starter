# Frontend Developer Guide
This file redirects AI agents to the main developer guidelines in the root folder.

For all architectural instructions, rules, and configuration steps, please read ../AGENTS.md.

The frontend follows the parent/fork contract in the root guide. Keep site
content, theme, assets, Markdown, and fork-owned routes local; do not edit
shared components, shared/app messages, generated i18n wiring, or integration
transport. If a reusable change is needed, propose it in the parent first.
