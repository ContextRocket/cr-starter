## About this template

This is an example long-form **site** document. It lives outside the i18n
message tree because it is editorial, page-length content owned by
[the content team](/faq) rather than short UI labels.

The `FileSiteContentSource` adapter reads this file, strips the frontmatter,
and renders the body to a trusted HTML string for the page component.

### Editing

Replace this copy with your own before going live. Add `about.es.md` and
`about.de.md` to translate it; a missing locale file is an honest `null`, not
an error.
